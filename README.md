# ExcelFormatter

Python + openpyxl を使い、指定フォルダ内の Excel（`.xlsx`）ファイルをまとめて整形するツールです。

## 動作環境

- Python 3.10 以上
- openpyxl 3.1.5（動作確認済み）

ライブラリが既に入っているか確認する場合：

```cmd
python -c "import openpyxl; print(openpyxl.__version__)"
```

## 使用方法

```cmd
python ExcelFormatter.py "C:\ExcelData"
```

引数を省略した場合は、起動後に対象フォルダのパスを入力できます。

## 処理仕様

1. 指定フォルダ直下とすべてのサブフォルダを再帰的に検索し、`.xlsx` ファイルを取得します。
2. 各ブックの**全ワークシート**で、B1セルの文字列にファイル名（拡張子 `.xlsx` を除く）が含まれるかを判定します。
3. 各シートの**使用範囲内のセル**について、横位置を左揃え、縦位置を中央揃え、折り返し表示を有効にします。
4. B1にファイル名を含む場合は **上2行固定**（`A3`）、含まない場合は **上1行固定**（`A2`）に設定します。
5. 変更後のファイルを**元ファイルに上書き保存**します。

たとえば `Book1.xlsx` のB1が `月次集計 Book1` なら上2行固定、`月次集計` なら上1行固定です。文字列の判定は大文字・小文字を区別します。

Excelが生成する一時ファイル（名前が `~$` で始まるもの）とバックアップフォルダは検索対象から除外します。

## バックアップ

元ファイルを上書きする前に、指定フォルダ直下の `_xlsx_backup` に**初回の元ファイル**をバックアップします。バックアップ内でも元のフォルダ構造を保ちます。

```text
C:\ExcelData\
├── フォルダA\Book1.xlsx
└── _xlsx_backup\
    └── フォルダA\Book1.xlsx
```

同じパスのバックアップが存在する場合は再作成しないため、2回目以降の実行でも最初のバックアップが残ります。

## 注意事項

- ファイルを編集する前に、対象のExcelブックを閉じてください。
- 特殊な図形・一部のExcel固有機能などは、openpyxl による保存時に完全に維持されない場合があります。重要なファイルではコピーでテストしてください。
- 書式設定の対象はシート全体（約100万行×約1万6000列）ではなく、**使用範囲内**です。
- 処理結果はコマンドプロンプトにファイル別・シート別に表示されます。
